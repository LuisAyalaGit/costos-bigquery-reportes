Eventos de Set-Top Box: BigQuery vs DynamoDB vs ClickHouse vs Aurora

Estimado de cuánto costaría manejar el flujo de eventos del Set-Top Box, calculado sobre 75 millones de eventos al día. Se comparan 5 opciones: BigQuery, DynamoDB, ClickHouse (en sus dos versiones — una que tú instalas y administras, y otra ya administrada por el proveedor) y Amazon Aurora. Todos los precios son públicos y de lista, sin ningún descuento especial — el detalle de cómo se calculó está al final.
🔁

Actualización: el volumen base cambió de ~11.4M a 75M eventos/día (6.56× más), se agregó ClickHouse Cloud junto al autoalojado, y se agregó Amazon Aurora como quinta opción. Todas las cifras de abajo ya reflejan estos cambios.

Consideraciones más allá del costo

BigQuery

  • Ya es la herramienta que usan hoy — sin curva de aprendizaje ni proveedor nuevo
  • Exige particionar/clusterizar bien la tabla desde el día 1 para que el costo no se dispare
  • Excelente para analítica ad-hoc y cruces con las tablas que ya existen

DynamoDB

  • Muy bueno para escritura masiva de baja latencia (lo que piden los devs)
  • No es un motor analítico — para reportes/BI necesitarías exportar (ej. a S3 + Athena) o hacer streaming a BigQuery de todos modos
  • Costo de almacenamiento por GB es ~25× más caro que BigQuery a largo plazo

ClickHouse (autoalojado)

  • Pensado justo para este caso: ingesta masiva + analítica rápida en la misma tabla
  • Software libre (Apache 2.0) — el costo es solo la infraestructura donde corre, sin cuota de proveedor
  • A cambio, exige alguien del equipo que lo opere (parcheo, escalado, respaldo, alta disponibilidad) — costo real pero no está en dólares en esta tabla

ClickHouse Cloud

  • Mismo motor OLAP, versión administrada — sin operarlo tú, y a este volumen sale más barato que el autoalojado (~$776/mes vs. ~$870–890/mes)
  • Corre en AWS, GCP o Azure — no ata a un solo proveedor de nube
  • El tier Basic no tiene alta disponibilidad real; para eso hace falta Scale, que es lo que se cotizó aquí

Aurora

  • Es una base de datos relacional (transaccional) — no fue diseñada para el patrón de "firehose" de eventos que describen los devs, a diferencia de ClickHouse/DynamoDB/BigQuery
  • Tiene sentido si además necesitas transacciones ACID clásicas (ej. cuentas, saldos) en la misma base
  • Serverless v2 escala solo, pero dimensionar bien los ACU para 75M escrituras/día requiere pruebas de carga reales — el número aquí es una referencia, no una garantía

Metodología: volumen base = 75,000,000 eventos/día (dato recalculado por el equipo, reemplaza la extrapolación anterior de 3M/150 mil STB). Tamaño de evento en 3 escenarios; "medio" ancla en el tamaño promedio real de fila de KPIS.EventMKP (1,162,372,610,843 bytes ÷ 3,020,679,692 filas ≈ 385 B). BigQuery: almacenamiento $0.02/GB activo (90 días) + $0.01/GB largo plazo, ingesta vía Storage Write API $0.025/GiB con 2 TiB/mes gratis, queries a $6.25/TiB on-demand (mismo supuesto validado contra factura real en el resto de esta carpeta); el rango "bien/mal diseñada" escala el caso real de KPIS.EventMKP (documentado en 21_impacto_eventmkp_jul_ago.sql) por la razón entre el nuevo volumen diario y el usado en el estimado anterior (×6.56). DynamoDB On-Demand, tabla Standard, región US East: $0.625/millón WRU, $0.25/GB-mes de almacenamiento (evento ≤1KB = 1 WRU). ClickHouse® es software open source (Apache 2.0) que se autoaloja, distinto de ClickHouse Cloud (el servicio administrado de pago) — aquí se usa el costo de infraestructura de un clúster autoalojado de alta disponibilidad (3 nodos, 8 vCPU/32 GB cada uno en AWS), ~$870–890/mes todo incluido (cómputo + almacenamiento + red), referencia dimensionada para cargas de decenas de GB/día como las de este estimado; no incluye el tiempo de operación del equipo. Amazon Aurora: Serverless v2 en modo I/O-Optimized, $0.156 por ACU-hora (1 ACU ≈ 2 GB de RAM + CPU/red proporcional) — se asumen 8 ACU sostenidos como referencia de dimensionamiento para el volumen de escritura estimado, sin haber corrido pruebas de carga reales; almacenamiento I/O-Optimized $0.225/GB-mes (evita el cargo de $0.20/millón de requests del modo Standard, más impredecible para un flujo de escritura tan grande).
